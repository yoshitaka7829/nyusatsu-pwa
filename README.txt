入札申請ナビ v0.1（第1週・試作版）
================================
内容：自治体の登録・編集・削除、検索、絞り込み、お気に入り、期限表示、JSONバックアップ/復元、CSV出力、端末内保存。
初期データは自治体の例示のみ。公式情報や申請期間は未入力です。Googleカレンダー・Drive連携や自動調査は未実装です。

【Windowsでまず試す】
1. ZIPを展開する
2. 展開フォルダの index.html をダブルクリック
3. 「自治体を追加」や「編集」を使ってみる
※ ローカルファイルとして開く場合、オフライン用Service Workerは動きません。端末内保存などの基本機能は使えます。

【Androidでも利用するには】
無料のGitHub Pages等でHTTPS公開する必要があります。
1. GitHubアカウントを用意し、新しいPublicリポジトリを作る（例 nyusatsu-pwa）。
2. ZIPの中身6ファイルをリポジトリの最上位へアップロード（ZIPのままでは不可）。
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save。
4. 数分後に表示される https://ユーザー名.github.io/nyusatsu-pwa/ をAndroidのChromeで開く。
5. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ。
※ 公開リポジトリ内のコードは誰でも閲覧可能。個人情報・APIキー・パスワードは絶対に置かないでください。
※ この試作版はlocalStorage保存のためPCとAndroidのデータは同期しません。JSONの書き出し/復元で手動移行できます。
※ ブラウザのサイトデータを削除すると入力内容が消える可能性があります。定期的にJSONバックアップしてください。
※ GitHub Pagesは静的ファイルの配信のみで、自治体の自動巡回は行いません。
